# Fresh-Pulse-Retail-Operations-Analysis
Relational database design &amp; SQL analytics project for an e-commerce grocery platform (Fresh Pulse) and a Power BI dashboard to surface customer, product, and inventory insights.
# Domain:
E-Commerce / Grocery Retail Management 
# Type:
SQL Mini Project — Database Design + Business Analytics 
# Tech Stack:
MySQL (RDBMS) · Power BI
- # Key insights
- Top Products & Categories — ranked by total sales to identify top revenue drivers
- Inventory Health — stock levels by product/category with Low Stock alerts
- Supplier & Catalog Scale — Active Suppliers and Total Products tracked
