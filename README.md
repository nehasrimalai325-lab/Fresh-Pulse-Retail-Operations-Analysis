# Fresh-Pulse-Retail-Operations-Analysis
Relational database design &amp; SQL analytics project for an e-commerce grocery platform (Fresh Pulse) and a Power BI dashboard to surface customer, product, and inventory insights.
# Project Overview
Domain: E-Commerce / Grocery Retail Management 
Type: SQL Mini Project — Database Design + Business Analytics 
Tech Stack: MySQL (RDBMS) · Power BI
Amazon Fresh needed a structured way to manage growing volumes of customer, product, supplier, order, and review data — and to turn that data into insights that support decisions on inventory, customer retention, and marketing. This project builds that database from the ground up and answers real business questions with SQL, then visualizes the findings in a dashboard.
# Objective
- Analyze customer spending, order activity, and product demand
- Monitor stock levels, supplier performance, and customer satisfaction (ratings)
- Generate actionable business insights through SQL queries and a BI dashboard
- # Conclusion
This project demonstrates how relational database techniques — schema design, constraints, joins, subqueries, window functions, and normalization — can transform raw transactional data into actionable business intelligence. It delivers a functional architecture capable of auditing inventory, tracking buyer behavior, evaluating supplier performance, and measuring overall store performance.
